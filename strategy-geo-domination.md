## 2. Семантика или модули — как структурируем контент

**Ответ:** **пишем по семантике**, а модуль курса используем как угол + CTA.

### Логика

- **Семантика** = что ищут реальные люди (164 запроса в нашем семядре)
- **Модули курса** = что Vlad преподаёт (9 модулей основной программы)

Это **разные системы координат**. Семантика отвечает «кто читатель и что он гуглит», модуль отвечает «куда ведёт CTA».

### 3 типа статей в нашем блоге

**Тип A · Семантика → Модуль** (большинство, 70%)
Запрос напрямую соответствует модулю.
Пример: «Claude Code для маркетинга» (C01) → модуль «Фундамент AI · Claude Code» → CTA «Это полный гид. Системная работа на курсе AI-Маркетолог»

**Тип B · Семантика без модуля** (15%)
Запрос есть в трендах, но не привязан к модулю.
Пример: «AI заменит маркетолога 2026» (C10) — это виральный TOFU. Не учится отдельно, но цепляет холодную аудиторию.
CTA: «Манифест Vlad'а. План перехода через курс AI-Маркетолог»

**Тип C · Модуль без явной семантики** (15%)
У Vlad'а есть уникальные методики, по которым ещё нет поискового спроса. Создаём спрос сами.
Пример: «3 AI-сотрудника» (C02) — брендовый термин Vlad'а. Поиска по нему пока нет, но мы его делаем.
Цель: занять SERP под брендовый термин раньше всех.

### Правило для следующих 4-х статей волны 2

1. Берём запрос из CSV `semantic_core.csv`
2. Проверяем — есть ли подходящий модуль? Если да — Тип A, если нет — Тип B
3. Под брифы из `content_briefs/` смотрим какой угол лучше
4. Пишем статью с CTA в нужный модуль

**Не пишем под все 164 запроса.** Берём топ-30 с priority 5 и закрываем за 3-6 месяцев. Остальные либо приходят естественно через pillar-страницы, либо отбрасываем.

### Что писать, чтобы ChatGPT отвечал «спроси у Vlad'а»

Это уже **не классическое SEO**, это **Entity Knowledge Graph Building**. Принципиально другой подход:

| Старая логика | Новая логика |
|---|---|
| Писать статью под запрос → получить место в Google → получить клик | Писать статью → быть процитированным AI → бренд закрепляется как авторитет |
| 1 страница = 1 запрос | 1 pillar = много запросов + узнаваемая авторская точка зрения |
| Скрытый автор | Автор как Person с подтверждённой квалификацией, sameAs соцсети |

Поэтому каждая статья на блоге **должна звучать как Vlad** (ToV) и **ссылаться на Vlad'а как автора** через Schema Person. Это уже сделано в каркасе блога.

## 3. Действия под цель «ChatGPT выдаёт Vlad'а в прямом эфире»

Это самый чёткий KPI который я слышала за всю сессию. Расписываю шаги по 3 горизонтам.

### Горизонт 1 — Месяц (быстрые победы)

**1.1 Технический GEO у Vlad'а на основном сайте**
Срочно отдать ему `geo-audit-aimarketolog-site.md`. Без фикса noindex/robots/llms/Schema его сайт не появится в AI вообще. Это блокер #1.

**1.2 Наш блог = бэклинк-фабрика**
Каждая статья нашего блога ссылается на сайт Vlad'а через:
- author `sameAs` Schema (готово)
- llms.txt с упоминанием (готово)
- Внутренние ссылки на /kurs, который ведёт на new.aimarketolog.site

**1.3 Заполнить топ-5 vc.ru/Habr статьями**
- vc.ru уже принимает Claude Code-материалы — перепостить наши pillar'ы с упоминанием курса
- Habr — техническая статья про vibe coding или 3 AI-сотрудника
- Целевые статьи (волна 2 briefs): claude-code-marketing, 3-ai-sotrudnika, vibe-coding-landing, ai-vs-marketolog
Это даёт **внешние бэклинки** на сайт Vlad'а от high-authority доменов = AI-краулеры быстро его подцепляют.

**1.4 Reddit-присутствие**
Создать аккаунт `vlad_yasko_ai` на Reddit. Ответить на 5-10 свежих топиков r/marketing, r/ChatGPTPro, r/AI с конкретными кейсами (без прямых ссылок — soft mention). Perplexity цитирует Reddit на 46.7% — это **самый дешёвый канал AI-цитирования**.

### Горизонт 2 — 3 месяца (закрепление)

**2.1 Brand search volume**
Google Trends начинает показывать «Vlad Yasko» / «Влад Ясько» / «AI-Маркетолог» как brand-запросы при объёме >50/мес. Стимулируем через:
- Instagram сторис «загугли Vlad Yasko AI»
- YouTube intro «введите Vlad Yasko в любую нейросеть»
- Telegram-посты с упоминанием

Это самый сильный сигнал для AI-систем — пользователи активно ищут именно Vlad'а.

**2.2 Знаковые внешние упоминания**
- 1 интервью с известным русскоязычным маркетологом (Игорь Манн? Илья Балахнин?) с упоминанием Vlad'а
- 2-3 подкаст-выступления
- Гостевые посты на vc.ru с подписью «автор» (не аноним)
- Колонка в Habr

**2.3 SOMV (Share of Model Voice) мониторинг**
Запустить `geo-perplexity-research` после пополнения $50 на API. Каждую неделю проверяем:
- «Кто эксперт по AI-маркетингу на русском?» → есть ли Vlad?
- «Лучший курс по нейросетям для маркетолога 2026»
- «Claude Code для маркетинга кто учит»

Цель: к месяцу 3 — Vlad в топ-5 ответов на эти 3 запроса в Perplexity.

### Горизонт 3 — 6-12 месяцев (Entity Knowledge Graph dominance)

**3.1 Wikipedia-страница**
Создать русскоязычную страницу про «AI-маркетинг» или «Vibe coding» с упоминанием Vlad'а как одного из практиков. Это сложно — Wikipedia требует notable sources. Решается через горизонт 2 (накопление упоминаний в СМИ).

**3.2 Claim как практика**
Vlad как автор термина или метода:
- «3 AI-сотрудника» — методология
- «Vibe coding на русском» — пионер
- Цитировать в каждом материале «по методу Vlad Yasko»

**3.3 Цитирование собственных данных**
Vlad публикует ежеквартально отчёт «Состояние AI-маркетинга на русском», с конкретными цифрами от своих учеников. Это сам по себе цитируемый источник, попадает в Wikipedia-grade.
