# Page Templates · AI-Маркетолог Blog

5 шаблонов покрывают все страницы MVP: `home` · `blog-index` · `pillar` · `article` · `kurs` · `about`.

Каждый шаблон описан как: **layout-зоны → компоненты → данные → SEO/GEO примитивы**.

---

## 1. `home` — Главная (`/`)

**Цель:** холодный читатель за 5 секунд понимает: что это, для кого, кто автор, и куда дальше.

```
┌──────────────────────────────────────────────────────┐
│ HEADER (sticky)                                       │
├──────────────────────────────────────────────────────┤
│ HERO                                                  │
│   H1: Блог про AI-маркетинг от Vlad Yasko             │
│   Sub: 9 модулей курса разобрано в открытых статьях   │
│   [Залетай на курс →]   [Читать блог →]               │
├──────────────────────────────────────────────────────┤
│ HERO-METRICS (3 числа)                                │
│   2660 учеников · 12+ ниш · $120K кейс запуска        │
├──────────────────────────────────────────────────────┤
│ PILLAR-GRID (карточки 12 кластеров, по 4 в ряд)      │
│   [C01 Claude Code] [C02 3 AI-сотрудника] [C03 Vibe] │
│   [C10 AI vs Маркетолог] ...                          │
├──────────────────────────────────────────────────────┤
│ LATEST-ARTICLES (3 свежих)                            │
├──────────────────────────────────────────────────────┤
│ VLAD-CARD (превью автора + ссылка /vlad)             │
├──────────────────────────────────────────────────────┤
│ CTA-BANNER (большой блок «Залетай на курс»)          │
├──────────────────────────────────────────────────────┤
│ FOOTER                                                │
└──────────────────────────────────────────────────────┘
```

**Компоненты:** `<Header/>` `<Hero/>` `<HeroMetrics/>` `<PillarGrid/>` `<LatestArticles/>` `<VladCard/>` `<CtaBanner/>` `<Footer/>`

**Данные:**
- Pillar-grid тянет из `lib/clusters.ts` (12 объектов с id, title, slug, description, icon)
- Latest-articles тянет 3 последние из `content/articles/*.mdx` (frontmatter)

**SEO/GEO:**
- `<title>`: «Блог про AI-маркетинг от Vlad Yasko · 9 модулей курса в открытых статьях»
- `<meta description>`: «Разбираем Claude Code, AI-агентов, vibe coding, упаковку продукта. Готовые статьи под курс AI-Маркетолог 2.0»
- JSON-LD: `WebSite` + `Organization` (курс) + `Person` (Vlad)
- OG-image: динамический через `app/opengraph-image.tsx`

## 2. `blog-index` — Список статей (`/blog`)

**Цель:** холодный читатель ищет статью по теме, видит все 12 pillar и переходит в нужный.

```
┌──────────────────────────────────────────────────────┐
│ HEADER                                                │
├──────────────────────────────────────────────────────┤
│ BREADCRUMBS: Главная > Блог                           │
├──────────────────────────────────────────────────────┤
│ PAGE-HERO                                             │
│   H1: Все статьи блога AI-Маркетолог                  │
│   Sub: 12 тематических столпов под 9 модулей курса    │
├──────────────────────────────────────────────────────┤
│ CLUSTER-FILTER (горизонтальный ряд тэгов C01-C12)    │
├──────────────────────────────────────────────────────┤
│ ARTICLES-GRID (3 колонки на desktop)                  │
│   - сортировка: pillar сначала, потом spoke           │
│   - на каждой карточке: тэг кластера + дата + время   │
├──────────────────────────────────────────────────────┤
│ CTA-BANNER                                            │
├──────────────────────────────────────────────────────┤
│ FOOTER                                                │
└──────────────────────────────────────────────────────┘
```

**Компоненты:** `<Header/>` `<Breadcrumbs/>` `<PageHero/>` `<ClusterFilter/>` `<ArticlesGrid/>` `<CtaBanner/>` `<Footer/>`

**Данные:**
- `content/articles/*.mdx` через `getAllArticles()`
- Фильтр по кластеру = client-side через URL query `?cluster=C01`

**SEO/GEO:**
- `<title>`: «Все статьи блога AI-Маркетолог · 12 тематических столпов»
- JSON-LD: `Blog` + `BreadcrumbList`
- `<link rel="canonical">` без query параметров

## 3. `pillar` — Pillar статья (`/blog/[pillar-slug]`)

**Цель:** холодный читатель попадает на pillar из поиска/AI, читает 2500-3500 слов, кликает в один из spoke или CTA на курс.

```
┌──────────────────────────────────────────────────────┐
│ HEADER                                                │
├──────────────────────────────────────────────────────┤
│ BREADCRUMBS: Главная > Блог > [Pillar Title]          │
├──────────────────────────────────────────────────────┤
│ ARTICLE-HERO                                          │
│   Тэг кластера (жёлтый)                               │
│   H1                                                  │
│   Sub-описание (1-2 строки)                           │
│   Мета: Vlad + дата публикации + дата обновления +   │
│         время чтения (X мин)                          │
├──────────────────────────────────────────────────────┤
│ TL;DR-BLOCK (выделенный жёлтой полосой слева)        │
│   5-7 строк прямого ответа                            │
├──────────────────────────────────────────────────────┤
│ [SIDEBAR-LEFT  ]  CONTENT (MDX)                       │
│ [ TOC          ]  H2 1                                │
│ [ progress bar ]    Прямой ответ в первых 100 словах  │
│ [ CTA card     ]    Тело                              │
│ [             ]   H2 2                                │
│ [             ]   ...                                 │
├──────────────────────────────────────────────────────┤
│ FAQ-ACCORDION (Schema FAQPage)                        │
├──────────────────────────────────────────────────────┤
│ AUTHOR-BIO (мини-карточка Vlad + ссылка /vlad)        │
├──────────────────────────────────────────────────────┤
│ SPOKE-LIST (карточки spoke-статей этого pillar)      │
├──────────────────────────────────────────────────────┤
│ RELATED-ARTICLES (3 карточки cross-cluster)           │
├──────────────────────────────────────────────────────┤
│ CTA-BANNER большой                                    │
├──────────────────────────────────────────────────────┤
│ FOOTER                                                │
└──────────────────────────────────────────────────────┘
```

**Компоненты:** `<Header/>` `<Breadcrumbs/>` `<ArticleHero/>` `<TldrBlock/>` `<Sidebar/>` `<Toc/>` `<ReadingProgress/>` `<MdxContent/>` `<PromptBlock/>` `<ToolMention/>` `<FaqAccordion/>` `<AuthorBio/>` `<SpokeList/>` `<RelatedArticles/>` `<CtaBanner/>` `<Footer/>`

**MDX-компоненты внутри статьи:**
- `<PromptBlock>` — блок с промптом для Claude (синий `#9333ea` фон, иконка Claude, кнопка «Копировать»)
- `<ToolMention name="Claude Code" />` — мини-чип с иконкой инструмента (используется inline в тексте)
- `<CaseCard title metric source />` — карточка кейса с большой жёлтой цифрой
- `<ComparisonTable cols rows />` — сравнительная таблица
- `<Quote author>` — цитата Vlad'а (жёлтая вертикальная полоса слева)
- `<Stat number caption />` — выделенная статистика
- `<Callout type="warning|tip|insight">` — выделенный блок

**Данные:**
- `content/articles/[slug].mdx` с frontmatter: `title`, `description`, `cluster` (C01-C12), `pillar` (true), `publishedAt`, `updatedAt`, `readingTime`, `tldr`, `faq` (массив Q&A)
- TOC генерируется автоматически из H2 + H3 через rehype-slug

**SEO/GEO:**
- `<title>`: H1 + «· AI-Маркетолог»
- `<meta description>`: brief.description (160 символов)
- JSON-LD: `Article` + `Person` + `Organization` + `BreadcrumbList` + `FAQPage`
- OG-image: динамический через `app/blog/[slug]/opengraph-image.tsx` (тёмный + жёлтый акцент + заголовок)
- `<link rel="canonical">`
- `<meta name="article:published_time">`, `<meta name="article:modified_time">`

**Контент-правила (для копирайтера / content-system:article-creator):**
- Под каждым H2 — прямой ответ в первых 100-150 словах (Island Test, перевёрнутая пирамида)
- Длина пассажа 134-167 слов
- 1 image / диаграмма на 500 слов (мультимодальность +156% цитирование)
- 5-10 внутренних ссылок на 1000 слов
- ToV-маркеры Vlad'а: 3+ за статью (движ, залетай, машина, на коленке)
- Цитаты Vlad'а через `<Quote author="Vlad">` минимум 1
- Конкретные цифры везде где можно

## 4. `article` (spoke) — Spoke статья (`/blog/[pillar-slug]/[spoke-slug]`)

Тот же шаблон что pillar, отличия:
- Короче (800-1500 слов вместо 2500-3500)
- Breadcrumbs: `Главная > Блог > [Pillar] > [Spoke Title]`
- В первом абзаце обязательная ссылка на pillar: «Полный гид по [теме] читай в [pillar →]»
- Sidebar без CTA-карточки (экономим место)
- Spoke-list НЕ показываем (spoke не имеет своих spoke на MVP)
- Related-articles показываем 3: 1 другой spoke этого же pillar + 1 pillar + 1 cross-cluster

JSON-LD `Article` + `BreadcrumbList` (3 уровня вместо 2) + опционально `HowTo` если статья пошаговая (кейс «нумеролог за 60 минут» = `HowTo`).

## 5. `kurs` — Лендинг курса (`/kurs`)

**Цель:** холодный читатель пришёл из CTA статьи. За 30 секунд понимает что такое курс, видит цены, кликает «Узнать больше» → ведёт на `aimarketolog.site`.

**НЕ дублируем** лендинг Vlad'а. Делаем короткий мост.

```
┌──────────────────────────────────────────────────────┐
│ HEADER                                                │
├──────────────────────────────────────────────────────┤
│ BREADCRUMBS: Главная > Курс                           │
├──────────────────────────────────────────────────────┤
│ KURS-HERO                                             │
│   H1: AI-Маркетолог 2.0 — собственная ИИ-команда     │
│        за 9 недель                                    │
│   Sub: 26 AI-сотрудников, 8 модулей, реальная        │
│        практика без лекций                            │
│   Vlad-фото слева, текст справа                       │
│   [Полная программа на aimarketolog.site →]          │
├──────────────────────────────────────────────────────┤
│ HERO-METRICS                                          │
│   9 недель · 26 AI-сотрудников · 4 тарифа $397-$3408 │
├──────────────────────────────────────────────────────┤
│ WHAT-INSIDE (8 модулей в bento-grid)                  │
│   Каждый модуль = карточка с иконкой + 2-3 строки    │
├──────────────────────────────────────────────────────┤
│ WHO-FOR (3 типа аудитории)                            │
├──────────────────────────────────────────────────────┤
│ PRICING-PREVIEW (4 тарифа сжато)                      │
├──────────────────────────────────────────────────────┤
│ FAQ-ACCORDION (5-7 вопросов)                          │

│   [Перейти на aimarketolog.site]                     │
├──────────────────────────────────────────────────────┤
│ FOOTER                                                │
└──────────────────────────────────────────────────────┘
```

**Компоненты:** `<Header/>` `<Breadcrumbs/>` `<KursHero/>` `<HeroMetrics/>` `<ModuleGrid/>` `<WhoFor/>` `<PricingPreview/>` `<FaqAccordion/>` `<FinalCta/>` `<Footer/>`

**Данные:**
- `content/kurs/modules.ts` — массив 9 модулей (id, title, icon, description)
- `content/kurs/tarify.ts` — 4 тарифа (name, price, includes)
- `content/kurs/faq.ts` — FAQ массив

**SEO/GEO:**
- `<title>`: «AI-Маркетолог 2.0 — курс Vlad Yasko · 9 недель практики»
- JSON-LD: `Course` (полная разметка как в geo-audit рекомендации) + `Person` + `Organization` + `Offer` + `FAQPage`
- Ссылка на `aimarketolog.site` = `<a href rel="noopener" target="_blank">` (открывается в новой вкладке)

**Важно:**
- Эта страница НЕ конкурент сайту Vlad'а, она бэклинк-фабрика
- Все упоминания цены/программы дублируем как на основном сайте — для Entity consistency
- Ставим `<link rel="alternate" href="https://aimarketolog.site">` намекая что главный лендинг там

- `<title>`: «Vlad Yasko — преподаватель AI-маркетинга, автор курса AI-Маркетолог 2.0»
- JSON-LD: **`Person`** с полным набором:
  - `name`: «Vladyslav Yasko»
  - `alternateName`: [«Vlad Yasko», «Влад Ясько»]
  - `jobTitle`: «Marketing strategist, AI-marketing course creator»
  - `description`: 1 предложение
  - `image`: URL фото

  - `sameAs`: [Instagram, Threads, Telegram, YouTube, GitHub] — **критично для Entity Knowledge Graph**
  - `worksFor`: `Organization` курс
  - `knowsAbout`: [«AI marketing», «Claude Code», «Deep Research», «Marketing automation»]
  - `alumniOf` (если применимо)
- Плюс `Article` + `BreadcrumbList` + `FAQPage`

Каждая статья блога в `author` ссылается на `Person` с этим же `@id` = `/vlad#person`.

## Чек-лист готовности шаблона к публикации

- [ ] H1 + 5-15 H2 + опц. H3 (иерархия для TOC и для AI-parsing)
- [ ] TL;DR в начале (для AI и для скан-чтения)
- [ ] Под каждым H2 — прямой ответ в первых 100 слов
- [ ] Минимум 1 image/диаграмма на 500 слов
- [ ] FAQ-блок в конце с Schema FAQPage
- [ ] Author-bio Vlad'а с ссылкой /vlad
- [ ] 5-10 внутренних ссылок на 1000 слов
- [ ] Минимум 3 ссылки на pillar (если spoke) или на spoke (если pillar)
- [ ] 1 CTA на /kurs в конце + 1-2 контекстных в тексте
- [ ] JSON-LD: Article + Person + Organization + BreadcrumbList + FAQPage (+ HowTo если уместно)
- [ ] OG-image сгенерирован
- [ ] Canonical URL
- [ ] Meta description 150-160 символов
- [ ] Title 50-60 символов
- [ ] Дата публикации + дата обновления
- [ ] Reading time посчитан
- [ ] Цитата Vlad'а минимум 1
- [ ] ToV-маркеры 3+
- [ ] Без em-dash, без «воронка/лиды/прогрев»
- [ ] Конкретные цифры везде где можно
