# Стратегия совместного продукта Anna + Vlad

**Статус:** проектируется. Не согласовано с Vlad-ом. Все ниже как **предложение**, не как решение.

## Что предлагаю строить

Связку из двух Claude-скилов, которая закрывает полный цикл GEO для клиента: «найти разрыв → починить контент → отслеживать динамику».

**Скил 1: `geo-audit`** (уже собран, лежит в пакете `03-geo-skills/`)
Сайт на вход → технический аудит + промпт-тест + citation gap + готовая HTML-презентация для клиента.

**Скил 2: `geo-perplexity-research`** (будет собран, см. пакет `03-geo-skills/`)
Регулярный мониторинг видимости + Perplexity-research + topic gap discovery + конкурентный анализ. Использует Perplexity API ($50 бюджет готов).

## Технологический стек продукта (черновик)

| Компонент | Базовое решение | Премиум решение |
|---|---|---|
| Сайт под клиента | WordPress + Elementor | Astro + Vercel (вайб-кодинг через Claude Code) |
| Контентный конвейер | Zoom → Make → Claude → WP REST API | Make → Claude → Notion (ревью) → WP |

| Мониторинг (рост) | Otterly | Peec AI €89/мес |
| Мониторинг (enterprise) | Peec AI | Profound $99-499/мес |

Полный разбор в `RESEARCH-2026.md`. Главные числа:

- Мультимодальность +156-317% к цитированию
