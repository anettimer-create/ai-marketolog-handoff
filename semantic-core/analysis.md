## Стратегия GEO для этого блога

Наш блог сам должен быть **демо-стенд GEO** (это часть продающей логики курса).

### Технические условия (обязательно)

- **SSR через Next.js** (не CSR) — AI-боты не выполняют JS
- **robots.txt** с явным `Allow:` для GPTBot, ChatGPT-User, PerplexityBot, Perplexity-User, ClaudeBot, anthropic-ai, Google-Extended, Applebot-Extended, Meta-ExternalAgent, Bingbot
- **llms.txt** в корне — спецификация Answer.AI
- **Schema markup**: Article + Person (Vlad как автор) + Organization (Курс AI-Маркетолог) + BreadcrumbList + FAQ + HowTo на технических статьях
- **NAP consistency** для Entity Knowledge Graph: имя Vlad Yasko / Влад Яско / Vladyslav Yasko везде одинаково
- **Sitemap.xml** обновляемый
- **Open Graph + Twitter Cards** на каждой статье

### Контентные правила (обязательно)

- **Island Test** на каждом параграфе — извлеки, должен сохранить смысл
- **Перевёрнутая пирамида** в каждом H2: первые 1-2 предложения = прямой ответ, далее статистика, далее контекст
- **134-167 слов на пассаж** (среднее 157) — оптимум для AI-цитирования
- **Прямые цифры**: «$1500/день», «60 минут», «12→1 час» — а не «значительно быстрее»
- **Под каждым H2 = вопрос в естественной формулировке** (тот же, что задают в Perplexity)
- **Мультимодальность**: текст + графика + schema = +156% цитирование. Минимум 1 изображение/диаграмма на 500 слов
- **Свежесть**: дата обновления видна, обновляем раз в месяц (контент за 30 дней цитируется в 3.2× чаще)

### Структурные правила (обязательно)

- **TL;DR в первом блоке** статьи (5-7 строк)
- **Оглавление с anchor-links** сразу после TL;DR
- **FAQ-блок** в конце статьи (Schema FAQPage)
- **Хлебные крошки** на каждой странице
- **Внутренние ссылки spoke → pillar** в первых 100 словах
- **Author bio** (Vlad Yasko) с подтверждённой квалификацией = Entity authority
