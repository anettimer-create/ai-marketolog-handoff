# CLAUDE.md · Bootstrap для Claude Code в этом репо

Если ты Claude Code (или другой AI-ассистент) и тебя запустили в этой папке — прочитай этот файл первым, потом `README.md`.

## Что это за репо

Это **handoff-пакет** (пакет передачи результатов) работы Anna (Anettiya) над GEO-стратегией и блогом под курс **AI-Маркетолог** от Vlad Yasko. Anna проходит у Vlad'а менторинг; пакет собран чтобы Vlad мог скачать его и продолжить работу с тобой как с помощником.

**Важно понимать про природу репо:**

- Это **репозиторий документации и контента**, а НЕ приложение. Здесь нет исходного кода, `package.json`, тестов, линтеров или сборки. Не пытайся запускать `npm install`, искать точку входа или билдить — тут нечего билдить.
- Формат почти всех файлов — **Markdown** (плюс один HTML/PDF отчёт и JSON/CSV с семантикой).
- **Код блога живёт в отдельном репо:** https://github.com/anettimer-create/ai-marketolog-blog (Next.js + Vercel). Живой блог: https://ai-marketolog-blog.vercel.app. Этот handoff-пакет описывает архитектуру блога, но не содержит его.
- Язык репо — **русский**. Отвечай и пиши документы по-русски, если Vlad не попросит иначе.

## Что Vlad может попросить тебя сделать

### Сценарий A — починить его сайт

Vlad: «прогони мой сайт `new.aimarketolog.site` через geo-audit заново после моих правок»
→ Используй скилл `geo-audit` если он установлен, или вручную проверь по чек-листу из `geo-audit-aimarketolog-site.md`. Главные точки: убран ли ошибочный `noindex`, есть ли `/robots.txt`, `/sitemap.xml`, `/llms.txt`, добавлен ли JSON-LD (Course + Person + Organization + FAQPage).

### Сценарий B — написать новую статью

Vlad: «напиши мне статью про [тема]»
→ Найди соответствующий бриф в `semantic-core/content_briefs/`.
→ Если бриф есть — пиши по нему (с ToV Vlad'а из `stories-yasko`, если этот скилл установлен).
→ Если брифа нет — сначала найди кластер в `semantic-core/cluster_map.md` и `analysis.md`, потом пиши с нуля по той же структуре брифа (H2-план, GEO-вопросы под Perplexity, схема markup, ToV-маркеры).

### Сценарий C — мониторинг цитирования

Vlad: «проверь, цитируют ли меня в Perplexity по запросу X»
→ Используй скилл `geo-perplexity-research` если установлен. Требует `PERPLEXITY_API_KEY` в env.

### Сценарий D — развернуть блог локально

Vlad: «как мне поднять этот блог у себя»
→ Клонируй https://github.com/anettimer-create/ai-marketolog-blog (код НЕ в этом репо).
→ `npm install` → `npm run dev` → localhost:3000.
→ Деплой: связать с Vercel через GitHub-app.

### Сценарий E — объяснить или обновить документ

Vlad: «объясни что тут / обнови отчёт / собери резюме»
→ Читай нужные `.md`, объясняй простым языком. Если правишь `REPORT.html`, PDF пересобирается из него через Chrome headless (`--headless --print-to-pdf`).

## Ключевые факты и цифры (для консистентности)

- **Семантика:** 164 запроса, 12 кластеров (C01–C12), Hub & Spoke. Прямой конкурент — Евгения Одуд («Claude Code для маркетологов»). Дифференциация через бренд-термины Vlad'а: «3 AI-сотрудника», «AI-Ковчег», «vibe coding», «нумеролог за 60 минут».
- **Архитектура блога:** Next.js App Router + Tailwind + Vercel. SSR (не чистый CSR), глубина 2–3 уровня, один CTA = курс Vlad'а. JSON-LD на каждой странице. Детали и точная версия стека — в `architecture/README.md` (это источник истины по архитектуре).
- **GEO 2026:** Perplexity ~54% AI-реферального трафика, ChatGPT ~28%, Gemini ~11%, Claude ~5%. AI-трафик конвертит в разы лучше органики. Полная база с источниками — `RESEARCH-2026.md`; бери цифры оттуда, а не по памяти.
- **Сайт Vlad'а:** `https://new.aimarketolog.site` (это поддомен `new.`, НЕ `aimarketolog.site` — основная версия ещё в разработке).

## Конвенции контента (соблюдай в публичных текстах)

- **Vlad — реальный человек**, не клиент Anna. Они в стратегическом партнёрстве (Anna проходит менторинг, Vlad может стать партнёром по продукту).
- **Не используй слова «гуру», «коуч»** в текстах про Vlad'а — это против его позиционирования.
- **Без em-dash (—) в публичных текстах** — это AI-tell. В статьях и постах используй короткое тире или переформулируй. (В служебной документации репо em-dash допустим.)
- **ToV Vlad'а специфический:** «свой пацан, который взломал систему». Маркеры: движ, залетай, машина, на коленке, гиперценность, стакать, завод в кармане. Подробно в `stories-yasko/references/tov_yasko.md`, если скилл установлен.
- Избегай штампов «воронка / лиды / прогрев» и эмодзи в каждом предложении.
- **Palette блога:** чёрный `#000000` + жёлтый `#F5C518` (стиль Vlad'а), синий/фиолетовый точечно для Claude-акцентов.

## Что НЕ делать

- Не переписывать архитектуру блога без согласования с Vlad'ом — она спроектирована под GEO 2026, менять = терять преимущества.
- Не использовать чистый CSR без SSR — AI-краулеры не выполняют JS.
- Не убирать `llms.txt` / `robots.txt` / JSON-LD — они критичны для AI-цитирования.
- Не публиковать материалы с пометкой «личное» и данные со стратсессий Vlad'а без явного разрешения (таких файлов в публичном пакете нет, но если Vlad загрузит — соблюдай конфиденциальность).
- Не путать «Yasko» с «ESCO/ISCO» (частая ошибка транскрипций).
